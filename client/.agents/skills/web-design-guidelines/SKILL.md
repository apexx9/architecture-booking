# Web Interface Review
For requested UI audits, inspect source and rendered output when available. Review semantics, heading hierarchy, keyboard/focus, labels/errors, contrast, colour-only meaning, responsive overflow, control affordances, relevant UI states, reduced motion, layout shift and truncation. Report actionable findings with file/line references. Separate defects from preferences; do not rewrite unrelated code. For a formal Vercel guidelines audit, fetch https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md before reviewing.
