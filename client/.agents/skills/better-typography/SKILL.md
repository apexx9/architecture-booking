# Typography — Renove
Satoshi is the UI/body typeface; Zodiak is reserved for selected editorial/display moments. Establish a restrained scale and semantic heading hierarchy. Distinguish page titles, section headings, body, metadata and labels. Keep readable line lengths and line heights. Use tabular numerals for aligned data. Consider `text-wrap: balance` for headings and `pretty` for prose. Inspect actual content at narrow widths. Use the existing Tailwind/CSS system.
