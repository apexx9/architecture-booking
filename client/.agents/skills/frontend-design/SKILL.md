# Frontend Design — Renove
Read `DESIGN.md` first. Inspect existing routes/components before coding. Build production-quality interfaces with real, context-appropriate content. Use hierarchy, composition, typography and spacing—not gradients, heavy shadows, glass or excessive rounding. Preserve Satoshi and selective Zodiak use. Make responsive layouts intentionally. Keep domain logic and API decisions outside visual work. Review the rendered result, not just source code.
