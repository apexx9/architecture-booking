# Colour — Renove
Start from `app/globals.css` and its existing neutral values. Use semantic roles for canvas, surface, text, muted text, border, accent and status. Keep colour scarce and purposeful. Avoid gradients, neon and decorative saturated panels. Check contrast in actual rendered combinations. Never communicate status through colour alone. Use Tailwind v4 CSS-first tokens; do not add a v3 config.
