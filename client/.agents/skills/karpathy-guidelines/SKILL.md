# Focused Engineering Guidelines
Understand existing code before editing. Make the smallest complete change. Do not refactor unrelated code, add abstractions or dependencies without need, or make product decisions from assumptions. Preserve behaviour unless asked to change it. State uncertainty and ask when a requirement crosses into domain/API/state decisions. Run relevant checks and report exactly what changed and what was verified.
