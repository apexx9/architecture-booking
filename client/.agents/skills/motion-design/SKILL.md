# Motion Design

Use this skill whenever a page, component or interaction needs
motion design decisions.

## Responsibilities

Think like a motion designer, not simply a developer adding
CSS transitions.

For every animation, define:

- What triggers it?
- What is moving?
- What is the user's intended focus?
- What information does the movement communicate?
- How does it enter and leave?
- What happens when the user interrupts it?

## Choreography

Treat related elements as a coordinated composition.

Use staggered entrances only when they establish hierarchy.
Keep stagger intervals short enough to preserve responsiveness.

Do not animate unrelated elements in a random sequence.

## Spatial Continuity

When an element changes state, preserve a believable sense
of continuity between its previous and next positions.

Use consistent directional movement:
- Entering elements generally move into the composition.
- Exiting elements move away from it.
- Related transitions should use consistent directions.

## Easing

Choose easing based on the interaction:
- Ease-out for entrances.
- Ease-in for exits.
- Smooth ease-in-out for state changes.
- Spring motion for interactions requiring physical feedback.

Do not use dramatic elastic movement for ordinary business UI.

## Quality Checklist

- Does the movement have a clear purpose?
- Is the duration appropriate?
- Does it distract from content?
- Does it feel consistent with neighbouring components?
- Does it remain usable when repeated?
- Does reduced-motion behaviour work?
