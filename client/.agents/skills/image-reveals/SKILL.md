# Image Reveals

Use this skill for image-led storytelling and visual transitions.

Particularly relevant to Renove's architectural and
interior-design presentation.

## Techniques

- Overflow-hidden image reveals.
- Clip-path transitions.
- Subtle scale reveals.
- Image wipe transitions.
- Directional masks.
- Hover image movement.
- Layered image transitions.
- Scroll-based image entrances.

## Principles

The image should remain the visual subject.

Use restrained movement.
Avoid excessive zoom.
Avoid unnecessary filters.
Avoid decorative overlays that reduce image quality.

## Implementation

- Preserve image aspect ratios.
- Reserve image dimensions to avoid layout shifts.
- Use Next.js Image appropriately.
- Respect object-fit and object-position.
- Avoid unnecessary large image layers.
- Ensure clipping does not hide essential content.
- Handle image loading and failure states.

## Responsive Behaviour

Adjust reveal direction and complexity for smaller screens.

Do not assume the desktop composition works on mobile.

## Accessibility

Decorative images should have appropriate empty alt text
when they convey no additional information.

Meaningful images must retain descriptive alternatives.

Follow MOTION.md.
