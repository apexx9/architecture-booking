# Accessibility — Renove
Prefer semantic HTML and native controls. Label every input and associate hints/errors. Interactive elements must be keyboard operable with visible focus and accessible names. Use buttons for actions and links for navigation. Use ARIA only when it accurately describes behaviour. Manage focus and Escape for dialogs/drawers and restore focus on close. Respect reduced motion and sufficient contrast. Do not rely on colour alone.
